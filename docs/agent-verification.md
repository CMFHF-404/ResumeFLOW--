# Verification reference

Look up the affected feature only. This is a catalog of existing coverage, not a mandatory suite for every edit. Select tests by changed behavior and risk; explicit task acceptance checks remain required. Live probes and data mutations require an authorized target.

- Frontend: `npm run build`
- Frontend type-only checks: `npx tsc --noEmit --pretty false`
- Frontend targeted tests are plain Node test files under `tests/`. Run focused checks with `node --test tests/<file>.test.mjs`; for example `node --test tests/account-management-static.test.mjs` for account management, `node --test tests/experienceBankDrafts.test.mjs tests/experienceSimpleModeParser.test.mjs` for experience draft/simple-mode work, `node --test tests/dashboardStructure.test.mjs tests/dashboardUtils.test.mjs` for Dashboard list/filter work, or `node --test tests/appDevLoggingStructure.test.mjs` for app-shell development logging.
- Current six-dimension scoring uses `resume_score_v2` / `single_pass_v1`; related optimization uses `json_structure_v1`. Run `node --test tests/resumeScore.test.mjs` at the root and `python -B -m unittest test_resume_score` from `backend/` when those entrypoints change; select other relevant coverage below. Assert one scoring call, one selected-module planning call, at most one answered-module rewrite, no audit/repair calls, no automatic post-apply scoring, and zero calls for empty selections or skipped answers. Keep auth, save/version, HTML sanitization and scoped-write regressions.
- Historical scoring/semantic-review tests remain compatibility coverage. They must not reintroduce model audits or content regex gates into the current score/optimization entrypoints. Legacy apply/context fixtures explicitly call historical compatibility helpers; current production entrypoints are covered by `test_resume_score`.
- Six-dimension resume-optimization frontend changes can be covered by `node --test tests/resumeOptimizationNormalize.test.mjs tests/resumeOptimizationServiceStructure.test.mjs tests/resumeOptimizationFlowStructure.test.mjs tests/resumeOptimizationEntryStructure.test.mjs tests/resumeOptimizationWorkspaceStructure.test.mjs tests/resumeOptimizationQuestions.test.mjs tests/resumeOptimizationDisplayUtils.test.mjs tests/resumeOptimizationPreviewStructure.test.mjs tests/resumeOptimizationResultStructure.test.mjs tests/resumeOptimizationPostScoreFlow.test.mjs tests/resumeOptimizationAnalytics.test.mjs tests/resumeOptimizationAccessibility.test.mjs`.

These tests mock model verdicts; they verify the review contract and persistence boundaries, not live model accuracy. See `docs/ai-response-validation.md`.
