# 可执行信息取舍、专业证据与整段重排

本轮完成新执行入口、输入一致性、预览与撤销链路，并运行真实模型小批和完整批次尝试。**工程检查通过；模型质量验收未通过，完整批次未完成，v4灰度保持关闭。** 所有真实调用均使用 `gemini-3.5-flash-lite / medium`。

## 已实现

| 能力 | 用户操作与实际写入 |
|---|---|
| 课程取舍 | 只选择、重排已有课程，支持清空当前简历展示；保留括号内的成绩与说明，不新增或改名课程 |
| 教育说明 | 当前简历可编辑补充说明，进入预览、导出、评分快照及保存；AI可根据已有资料或确认后的事实整理 |
| 奖项与证书 | 独立隐藏及排序；隐藏修改当前简历选择，不删除共享记录 |
| 经历取舍 | 同类经历排序、独立隐藏、正文压缩；隐藏与正文改写不能捆绑冲突执行 |
| 专属技能 | 从已有经历的工具/方法原文提出候选，用户确认片段及分类后创建；采用`resume-skill:<uuid>`命名空间，支持当前简历编辑、移除及撤销 |
| 整段正文重排 | 一个勾选项授权该经历全部正文；原子写入`star.a`、清空已合并的`s/t/r`，保存前值；标题、单位、日期、类别及非目标字段不变 |

教育覆盖保存在`educationOverrides`，专属技能保存在`localSkills`，继续使用`skillOverrides`处理已存在技能的覆盖。编辑器、简历列表预览、PDF预览/导出、评分和JD上下文统一读取有效值；共享库不被修改。新增说明与专属技能进入配置快照及签名，恢复和撤销保留已有版本检查。

新动作由服务端目标目录绑定地址和允许选择的ID。课程过滤和排序、隐藏是确定性变换；技能创建/修改只组合用户确认的片段，均可减少不必要的模型调用。普通文字规划最多一次，回答后批量改写最多一次；没有审核、修复或自动复评调用。重复或冲突的方案、缺少全部必要确认、对象删除及版本变化不能继续应用；界面返回明确的冲突或确认数量提示。

报告保持“简短结论→可独立勾选方案→值得保留→折叠评分说明”，不展示原文引用、内部审阅记录或参考改写。写入之前仍显示修改预览与事实确认。

## 协议与输入

- 保持`resume_score_v4 / evidence_rubric_v2`，权重和档位映射不变；提示词升级为`resume_review_prompt_v7`，指南为`early_career_roles_v5`，输出结构为`review_json_schema_v4`，新方案策略为`json_structure_v3`。
- 每条建议增加策略类型、操作集合、执行前提及受约束的选择项。操作集合由程序根据目标生成，不接受模型自建路径。历史报告照常阅读，旧方案保留原应用与撤销。
- 完整正文只在阅读视图出现；字段块、来源目录及片段目录只提供内部地址和区间。课程列表保留原有课程文本及顺序，补充说明不再在编辑器构建链中遗漏。测试验证正文、课程、说明、技能边界与数据单位不丢失。
- 服务端仍执行完整结构、引用及写入范围校验。提供方只接收精简的形状约束，去掉重复枚举与重复对象分支；额外保存`serverSchemaHash`、`responseSchemaHash`和`providerSchemaVersion`，避免将两层校验混淆。
- A/B/C/D原生Schema从约157/185/194/122KB缩至约9.6/9.7/9.8/9.3KB。减少传输体积不等于已证明解决超时，成功率仍按实际调用记录判断。
- 不产生修改的“无需压缩/前置”判断可以没有片段引用；实际调整与具体保留证据仍须有效定位。未知引用、跨经历引用及ID元数据作为事实继续被拒绝。
