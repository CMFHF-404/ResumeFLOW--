# 规划契约、量表边界及无来源熟练程度修复

本轮已实施针对性修复，并取得标点及遗漏成果恢复的真实证据；**完整验收仍未通过**。最终规划重放为 6/8 成功，候选 17/18 获准（94.4%）；扩展审核门槛第一轮九项全对，第二轮传输失败，未启动完整盲测。

## 实施内容

1. 规划提示词嵌入与请求参数相同的动态 JSON schema，明确八个必填字段、空值及空数组规则。覆盖审核也显式提供完整输出契约。缺失字段仍整份拒绝；新增安全诊断记录任务路径、已知缺失字段和额外字段数量，不回显未知键或提供方正文。
2. 评分生成与独立审核共用 `resume_evaluation_rubric.py` 的证据规则，消除两处独立维护的专业表达说明。明确逐经历判断再汇总、求职方向的实际简历证据、轻微标点扣分、过程计数与数据可信度，以及访谈样本数与业务服务覆盖规模的区别。仍保留五个专业表达子项各 20 分，不按关键词密度评分。
3. 评分审核版本为 `resume_rubric_audit_v3`，共享规则和响应 schema 均进入凭据哈希；公共评分版本仍为 `coverage_consensus_v4`。不修改调用上限、总超时或模型。
4. 重放发现语义审核曾允许把已选技能标签写成“熟练运用”声明。新增本地来源检查，要求此类程度/专长声明有对应原文；技能名称、其他工具的熟练声明或模型的 supported 判定均不能替代来源。生成提示词同时要求中性列举技能。明确来源中的声明仍可保留。该规则较保守，未逐字保留的程度声明可能被拦截；本轮不放宽它来提高获准率。
5. 为无数据整理明确区分格式候选与表达缺陷：已有标点候选不代表重复和空泛已经修复，缺少事实不妨碍提供独立整理候选。
